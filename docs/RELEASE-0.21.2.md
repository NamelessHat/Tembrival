# Tembrival 0.21.2

Музыкальный плеер для Windows и Android: локальная библиотека, свои ленты и передача между устройствами по Wi-Fi. Регистрация и постоянный интернет для прослушивания не нужны.

## Возможности

- Треки, исполнители, альбомы, папки, плейлисты и избранное.
- Составные ленты из выбранных исполнителей, альбомов, плейлистов и отдельных песен. Пересечения убираются по идентификатору трека, порядок перемешивается при запуске. Составы лент пока хранятся отдельно на каждом устройстве.
- Очередь с перетаскиванием: боковая панель на широком экране и выдвижная очередь на телефоне.
- Передача музыки и синхронизация плейлистов и избранного через общий Wi-Fi или точку доступа телефона. Сопряжение по QR или вручную; после сопряжения используется TLS с проверкой ключа ПК.
- Дневная тема Tembrival и ночная Iskavell.

В публичной версии отсутствует загрузчик музыки из интернета. В 0.21.2 удалена зависимость удаления треков от личного загрузчика, а устаревшая ссылка на исключённый фон заменена актуальным изображением.

## Установка

- **Windows 10/11 x64:** скачайте `Tembrival-Windows.zip`, распакуйте всю папку и запустите `Tembrival.exe`. Один EXE без соседних файлов не переносите. Windows-сборка пока не подписана Authenticode; не отключайте защиту системы ради установки.
- **Android 8 и новее:** установите `Tembrival-Android.apk`. Для обновления установите поверх прежнего приложения, не удаляя его и не очищая данные. Сохранены прежние идентификаторы и подпись; окончательную установку подтверждает Android.
- `SHA256SUMS.txt` содержит контрольные суммы файлов. Это проверка целостности, а не отдельное подтверждение доверия к источнику.
- `FFmpeg-Electron-39.8.10-win32-x64-source.zip` — соответствующий комплект исходников runtime, патч и инструкции. Он также включён в Windows-поставку вместе с лицензиями.

Для передачи оба приложения должны работать в доступной друг другу локальной сети. VPN, брандмауэр и изоляция клиентов Wi-Fi могут мешать соединению. Первичная локальная выдача APK на ПК работает по HTTP в доверенной сети; это отдельный механизм от публичного HTTPS-сайта.
