Эти условия предназначены для собственных частей исходного кода, которые правообладатель отдельно опубликует с указанием на этот документ. ## Что разрешается

При соблюдении этих условий и сохранении имеющихся уведомлений об авторстве разрешается:

1. Читать и изучать опубликованный код, анализировать его работу и безопасность.
2. Получать локальную копию, собирать приложение и изменять код для собственного использования без распространения своих сборок или изменённого кода третьим лицам.
3. Направлять разработчику сообщения об ошибках и предложения исправлений, включая необходимые для этого изменения кода. Условия включения чужих исправлений в проект согласуются с их авторами отдельно; отправка предложения сама по себе не является передачей авторства.

Если иное не разрешено законом, отдельной лицензией применимого компонента или правилами платформы размещения, необходимо письменное разрешение правообладателя на:
