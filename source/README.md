# Исходники Tembrival 0.21.2

Это выбранные собственные исходники публичного варианта для Windows и Android без интернет-загрузчика. Автор — NamelessHat. Условия изучения, личных изменений и сборки: [LICENSE.md](LICENSE.md). Это source available, не Open Source; сторонние компоненты сохраняют свои лицензии.

## Подготовка

Установите Node.js 22 или новее и npm. В этой папке выполните `npm ci`, затем `npm test`. Electron закреплён на 39.8.10; зависимости восстанавливаются из package-lock.json. Для запуска Windows выполните `npm start`. Код не содержит пользовательской библиотеки или сохранённых подключений.

## Android, Windows PowerShell

Нужны JDK 17, Android SDK platform android-35 и build-tools 35.0.0. Задайте JAVA_HOME и ANDROID_SDK_ROOT. Выполните `./android/build.ps1 -Unsigned` для проверки компиляции. APK появится в release/Tembrival-Android.apk, но для установки его нужно подписать.

Для собственной подписи передайте -KeyStore и -KeyAlias и задайте TEMBRIVAL_STORE_PASSWORD и TEMBRIVAL_KEY_PASSWORD в окружении текущего процесса. Не сохраняйте пароли или ключи в репозитории. Официальный ключ отсутствует; собственная подпись не позволяет обновить официальную Android-установку. Сборка никогда не генерирует замену официального ключа.

После подготовки APK выполните `npm run package` для Windows. Результат — release/win-unpacked. Для обычного запуска Windows APK не требуется, он нужен для встроенной выдачи/обновления телефона. Linux и macOS не являются проверенными целевыми платформами этого набора.

Внутренние имена luma-music, local.luma.music и app.luma.local сохранены для совместимости данных и протокола. Не запускайте изменённую сборку с рабочим профилем без резервной копии; для отдельного профиля используйте параметр Electron --user-data-dir с новым каталогом.

Шрифт — Press Start 2P под SIL OFL (ui/assets/OFL-PressStart2P.txt). Оформление и процедурные звуки включены для отображения приложения; лицензия кода не предоставляет отдельного разрешения использовать оформление в самостоятельном продукте. История разработки, старые иллюстрации и сторонние музыкальные обложки не включены.

Electron содержит сторонний runtime, включая FFmpeg; [уведомления](THIRD-PARTY-NOTICES.txt) не заменяют полный комплект лицензий и соответствующих исходников, необходимый при распространении своей Windows-сборки. Соответствующий комплект для официального runtime будет доступен с публичным выпуском. Для личной сборки зависимости загружаются с официальных npm/Electron источников. Побайтовая воспроизводимость официальных ZIP/APK этим набором не заявляется.
